Zartour QR Code Generator

Overview

Zartour QR Code Generator is a lightweight web tool designed to create QR codes for the Zartour gamified exploration platform. The generator allows organizers to quickly produce unique QR codes that link players to quests, forms, routes, or rating pages used in the Zartour ecosystem.

These QR codes act as real-world checkpoints. When players scan a code, they are directed to a digital action such as completing a quest, rating a location, joining a challenge, or earning points.

The tool is designed to be simple, free to host, and easy to integrate with services like Google Forms, Jotform, Google Sheets, and static websites hosted on GitHub Pages.

---

Purpose

The QR generator powers the Zartour platform by turning physical locations into interactive game nodes.

Each QR code can represent:

- A quest location
- A tourism route checkpoint
- A challenge event
- A community activity
- A rating station for events or businesses

This system allows towns, tourism hubs, libraries, festivals, and local businesses to participate in a shared gamified network.

How It Works

1. Organizer creates a quest, event, or checkpoint.
2. A form or webpage is prepared for player interaction.
3. The link to that page is entered into the QR generator.
4. The generator produces a scannable QR code.
5. The QR code is printed or displayed at a physical location.
6. Players scan the QR code and complete the mission.

Each scan moves players further along the Zartour experience.

Installation

Step 1

Create a GitHub repository.

Step 2

Add an "index.html" file containing the QR generator script.

Step 3

Enable GitHub Pages in repository settings.

Step 4

Publish the site.

Your generator will now be accessible through your GitHub Pages URL.
